# 2026 4학년 뮤지컬 〈마틸다〉 온라인 전시관

## 포함 파일
- `grade4.html` : 독립적으로 작동하는 4학년 전시관 (4학년 1반/2반 포스터·소개·상영관·관람 소감)
- `styles.css`, `app.js` : 디자인과 영상·소감 기능
- `config.js` : 유튜브 영상 주소 2개, 소감 수집용 Apps Script 주소 설정
- `Code.gs` : 소감을 Google 스프레드시트에 저장하는 Apps Script 코드

## 1. 먼저 열어보기
`grade4.html`을 브라우저에서 바로 열면 화면을 볼 수 있습니다. 1반·2반의 실제 유튜브 링크가 이미 연결되어 있으며, 영상 소유자가 퍼가기를 허용하면 재생됩니다.

## 2. 유튜브 영상 연결 완료
- 4학년 1반 〈Naughty〉: https://youtu.be/5kKeT6T0hWQ
- 4학년 2반 〈Revolting Children〉: https://youtu.be/b_Fp5EFP9QE

영상 주소는 `config.js`에 이미 반영되어 있습니다. 변경하려면 해당 값을 수정하세요.

유튜브 소유자 계정에서 퍼가기(임베드)가 가능한지 확인해야 합니다. 링크가 있더라도 비공개 동영상은 일반 방문자가 볼 수 없습니다.

## 3. 관람 소감 기능
기본 상태는 **체험판**입니다. 작성한 소감은 *작성자가 사용하는 그 브라우저의 로컬 저장소*에만 저장되며 교사에게 전송되지 않습니다. 다른 기기에서 보이지 않고 브라우저 데이터 삭제 시 사라질 수 있습니다.

### 교사에게 실제로 전달되도록 연결하기
1. Google 스프레드시트를 하나 새로 만들고 외부에 공개하지 마세요.
2. 시트에서 **확장 프로그램 > Apps Script**를 열고 `Code.gs` 전체를 붙여 넣고 저장합니다.
3. **배포 > 새 배포 > 유형: 웹 앱**을 선택합니다. 실행 주체는 **나**, 접근 권한은 운영 환경에 맞게 설정합니다. 별도 로그인이 없는 외부 관람객도 의견을 보내려면 '모든 사용자' 접근이 필요할 수 있습니다. 이 설정은 엔드포인트가 공개되어 자동 입력/스팸에 노출될 수 있으므로 학교 보안 정책 검토와 시트 수시 확인을 권장합니다.
4. 배포된 웹 앱 URL(`https://script.google.com/macros/s/.../exec`)을 복사해서 `config.js`의 `feedbackEndpoint`에 넣습니다.
5. 다시 사이트에 접속해 시험 소감을 남기고, 실제 스프레드시트에 기록되는지 확인하세요.
6. Apps Script 코드를 수정하면 새 버전을 배포해야 반영됩니다.

**중요:** 브라우저의 교차 출처 제한 때문에 제출 성공 응답을 검증하지 않는 `no-cors` 방식입니다. 화면의 '제출 요청을 보냈습니다'는 서버 저장 완료를 뜻하지 않습니다. 반드시 시트에서 실제 도착 여부를 테스트하세요. 학생 이름·연락처 등의 개인정보를 남기지 않도록 지도하고, 댓글을 공개하지 말고 교사만 열람하도록 관리하세요. 공개 서비스에서는 스팸 방지와 개인정보 처리 방안을 함께 마련해야 합니다.

## 4. GitHub Pages로 독립 주소 만들기
1. GitHub에 새 저장소를 만듭니다(예: `school-musical`).
2. 웹페이지 구동 파일 네 개(`grade4.html`, `styles.css`, `app.js`, `config.js`)를 저장소 루트에 업로드합니다. `Code.gs`와 `README.md`는 참고 자료이며 웹 구동에 필요하지 않습니다. (`Code.gs`는 정적 웹페이지에서 실행되지 않고 Apps Script용 참고 파일입니다.)
3. **Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save**를 선택합니다.
4. 공개 URL 예: `https://사용자명.github.io/school-musical/grade4.html` (실제 계정에 따라 달라집니다.)
5. 나중에 학교 뮤지컬 중앙 허브에서 이 주소를 연결하면 됩니다.

## 운영·공유 유의점
- 학생 공연 영상은 학부모/학생 촬영·공유 동의, 학교 내부 지침, 원저작물 공연·촬영·온라인 게시 및 음원 이용 권리를 확인한 뒤 게시하세요. 뮤지컬 〈마틸다〉의 음악·대본에는 저작권이 있습니다.
- 유튜브의 **일부 공개**는 비공개가 아닙니다. 링크를 아는 사람은 다시 공유할 수 있습니다.
- GitHub Pages 정적 사이트는 공개 접근이 가능하며, 학생 실명이나 개인정보를 올리지 않는 것이 안전합니다.
- 현재 포스터는 무단 영화·공연 이미지 복제 없이 CSS로 만든 창작 그래픽입니다.
